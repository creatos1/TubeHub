Configuration

Important: This application requires API keys to function properly. Follow the instructions below to set them up.

YouTube Data API

Required for fetching video metadata from YouTube.

How to get your API key:
  1. Go to the Google Developers Console
  2. Create a new project or select an existing one
  3. Enable the YouTube Data API v3
  4. Go to "Credentials" and create an API key
  5. Copy the API key
Setting up in Replit:
  1. Click on "Secrets" tab in the left sidebar
  2. Click "New Secret"
  3. Set key as: YT_API_KEY
  4. Paste your YouTube API key as the value
  5. Click "Add Secret"
Status: {% if config.get('YT_API_KEY') %} ✓ Configured {% else %} ✗ Not configured {% endif %}

Discord Webhook

Required for sending video notifications to Discord channels.

How to get your webhook URL:
  1. Open Discord and go to your server
  2. Right-click on the channel where you want notifications
  3. Select "Edit Channel" → "Integrations" → "Webhooks"
  4. Click "New Webhook"
  5. Give it a name (e.g., "YouTube Hub")
  6. Copy the webhook URL
Setting up in Replit:
  1. Click on "Secrets" tab in the left sidebar
  2. Click "New Secret"
  3. Set key as: DISCORD_WEBHOOK
  4. Paste your Discord webhook URL as the value
  5. Click "Add Secret"
Status: {% if config.get('DISCORD_WEBHOOK') %} ✓ Configured {% else %} ✗ Not configured {% endif %}

Troubleshooting

Common Issues:
  • YouTube API quota exceeded: YouTube API has daily usage limits. If you exceed them, wait 24 hours or consider requesting a quota increase.
  • Video not found: Make sure the video is public and the URL is correct.
  • Discord webhook failed: Check that the webhook URL is correct and the channel still exists.
  • Database errors: The SQLite database is created automatically. If issues persist, restart the application.
Testing your setup:
  1. After setting up both secrets, restart your Replit
  2. Try adding a YouTube video using the "Add Video" page
  3. If successful, try sending it to Discord
Tip: You can also copy formatted messages for manual sharing on Facebook groups, Twitter, or other social platforms where API posting isn't available.
