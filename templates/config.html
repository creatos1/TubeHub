Solución de Problemas

Problemas Comunes:
  • Cuota de YouTube API excedida: La API de YouTube tiene límites diarios. Si los excedes, espera 24 horas o solicita un aumento de cuota.
  • Video no encontrado: Asegúrate de que el video sea público y la URL sea correcta.
  • Webhook de Discord falló: Verifica que la URL del webhook sea correcta y el canal aún exista.
  • Error de Facebook: Asegúrate de tener los permisos correctos y ser miembro del grupo. Los tokens de Facebook expiran periódicamente.
  • Errores de base de datos: La base de datos SQLite se crea automáticamente. Si persisten los problemas, reinicia la aplicación.
Probando tu configuración:
  1. Después de configurar ambas claves, usa los botones de prueba arriba
  2. Intenta agregar un video de YouTube usando la página "Agregar Video"
  3. Si es exitoso, intenta enviarlo a Discord
Consejo: También puedes copiar mensajes formateados para compartir manualmente en grupos de Facebook, Twitter u otras plataformas sociales donde no está disponible el posting automático.
